# مختبر العلوم — ثالث متوسط

موقع تعليمي تفاعلي عربي لمنهج العلوم للصف الثالث المتوسط في المملكة العربية السعودية.

**إعداد الأستاذة فاتن أبو سبل**

## تشغيل محلي

يمكن تشغيل الموقع مباشرة بفتح `index.html`، أو عبر خادم محلي:

```bash
python3 -m http.server 4173
```

ثم زيارة `http://localhost:4173`.

## النشر الدائم على GitHub Pages

1. أنشئي مستودعًا عامًا جديدًا في GitHub، مثل `science-third-intermediate`.
2. ارفعي **محتويات هذا المجلد** إلى الفرع `main`، بما فيها مجلد `.github` وملف `.nojekyll`.
3. من إعدادات المستودع افتحي **Settings → Pages**.
4. في قسم **Build and deployment** اختاري **GitHub Actions**.
5. انتظري اكتمال العملية من تبويب **Actions**؛ سيظهر رابط الموقع في **Settings → Pages**.

ملف `.github/workflows/pages.yml` ينفذ النشر تلقائيًا عند كل تحديث للفرع `main`، لذلك لا يحتاج الموقع إلى خادم أو قاعدة بيانات.

## المزايا

يحتوي الموقع على لوحة رئيسية، وحدات دراسية، نشاط تفاعلي عن الكثافة والطفو، مؤقت تركيز، اختبار قصير من خمسة أسئلة مع تصحيح فوري، وبطاقات مراجعة قابلة للقلب. يحفظ النقاط والمظهر الداكن محليًا في المتصفح.
